# Database Schema & Relational Design Specification
**Database Engine**: PostgreSQL 16+ with `pgvector` extension  
**ORM**: SQLAlchemy 2.0 (Declarative Mapped Models)  
**Migration Tool**: Alembic  
**Target Environment**: Containerized PostgreSQL / Google Cloud SQL / Amazon Aurora

---

## 1. Architectural Overview & Extensions

The database utilizes relational integrity with foreign keys for core transactional governance and leverages PostgreSQL extensions:
- **`pgcrypto` / `uuid-ossp`**: Native UUID generation (`gen_random_uuid()`).
- **`pgvector`**: 768-dimensional dense vector embeddings (`vector(768)`) generated by transformer encoders (`paraphrase-multilingual-mpnet-base-v2` or `DeBERTa-v4.2`) for semantic duplicate discovery and nearest-neighbor clustering (`HNSW` indexing).
- **`PostGIS` (or standard spherical GIS columns)**: `geometry(Point, 4326)` for geographic proximity queries and radial hotspot clustering.

## 3. Indexing & Query Optimization Strategy

```sql
-- 1. Full-Text Search on Grievance Descriptions & Titles (English & Hindi transliterations)
CREATE INDEX idx_grievances_title_desc_gin 
ON grievances USING GIN (to_tsvector('english', title || ' ' || description));

-- 2. HNSW Vector Index for Semantic Cosine Similarity Searches
CREATE INDEX idx_embeddings_hnsw 
ON grievance_embeddings USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);

-- 3. Composite Filtering on Status, Priority, and Department
CREATE INDEX idx_grievances_dept_status_priority 
ON grievances (department_id, status, priority);

-- 4. Spatial Geospatial Coordinate Indexing for Radius Queries
CREATE INDEX idx_grievances_lat_lng 
ON grievances (latitude, longitude);

-- 5. SLA Deadline Sorting Index for Risk Queues
CREATE INDEX idx_grievances_sla_deadline 
ON grievances (sla_deadline ASC) 
WHERE status NOT IN ('closed', 'citizen_verified');

-- 6. Audit Trail Fast Reverse-Chronological Scan Index
CREATE INDEX idx_audit_logs_timestamp 
ON audit_logs (timestamp DESC);
```
